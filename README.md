# 💻 UTS Pemrograman Web

## 📖 Deskripsi

Project ini dibuat sebagai tugas Ujian Tengah Semester (UTS) mata kuliah Pemrograman Web. Aplikasi ini dikembangkan menggunakan PHP, MySQL, HTML, CSS, JavaScript, dan Docker untuk membangun sistem berbasis web yang sederhana dan mudah digunakan.

---

## 🚀 Fitur

- Login Admin
- Dashboard
- CRUD Data
- Database MySQL
- Responsive Design

---

## 🛠️ Teknologi

- PHP
- HTML
- CSS
- JavaScript
- MySQL
- Docker

## ▶️ Menjalankan Project

Clone repository

```bash
git clone https://github.com/USERNAME/UTS-Pemrograman-Web.git
```

Masuk folder project

```bash
cd UTS-Pemrograman-Web
```

Jalankan Docker

```bash
docker compose up -d
```

Buka browser

```
http://localhost:8080
```
